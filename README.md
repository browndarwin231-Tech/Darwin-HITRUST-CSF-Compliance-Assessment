# Nova Care Cloud — HITRUST-Aligned Readiness & Gap Assessment
**Portfolio simulation | fictional healthcare technology company | no real PHI**

## Scenario
As a simulated GRC Analyst, evaluate eight **independently written** cybersecurity practice controls for a hypothetical healthcare provider preparing to explore HITRUST. This is a skills demonstration, **not** an official HITRUST e1/i1/r2 assessment, certification, or mapping of HITRUST requirement statements.

## Deliverables
- `HITRUST_Readiness_Gap_Assessment.xlsx`: Dashboard, Control Register, Evidence Tracker, Test Results, Findings, Sources & Scope.
- `sample_evidence/`: entirely fabricated exports for access, training, remediation, encryption, and vendors.
- `ASSESSMENT_PLAN.md`: scope, methodology, and limitations.
- `GAP_ANALYSIS_REPORT.md`: simulated results and recommended remediation.
- `ANALYST_EXERCISES.md`: exercises to complete and discuss in interviews.

## Simulated results
Eight practice controls: **3 passed, 3 failed, 2 not tested**. Six evidence records were received, two missing; five open findings. These numbers are based on the sample only and cannot be extrapolated to HITRUST assurance or actual HIPAA compliance.

## HITRUST context
HITRUST has e1, i1 and r2 assessment pathways. Its CSF v11.9 was released September 24, 2026. Official requirement statements and formal scoring methods are not reproduced here. To conduct a real scoped assessment, obtain the applicable official HITRUST content, determine the assessment type and scope, and use qualified assessors where appropriate.

## Run this project
1. Open workbook Dashboard, then Control Register.
2. Inspect each CSV under `sample_evidence/`.
3. Independently test two controls using `ANALYST_EXERCISES.md`.
4. Update test conclusions, remediation owner, due dates, and issue status as needed.
5. Explain how you would request missing evidence without treating it as a proven failed control.
